
# Office Map

Интерактивная карта офисных помещений на основе планов этажей. Проект позволяет просматривать помещения, находить сотрудников, отображать их расположение на плане и управлять размещением сотрудников и мебели.

## Основные возможности

- Просмотр планов этажей.
- Отображение контуров и номеров помещений.
- Выбор помещения и просмотр информации о нём.
- Отображение площади помещения.
- Просмотр списка сотрудников, закреплённых за помещением.
- Глобальный поиск сотрудников и помещений.
- Переход к сотруднику или помещению на другом этаже.
- Отображение сотрудников на плане с фотографиями или инициалами.
- Добавление, перемещение и удаление сотрудников на плане.
- Импорт контуров помещений из DXF.
- Импорт мебели из DXF с сохранением цветов и заливок.
- Каталог мебели и размещение мебели на плане.
- Перемещение и поворот мебели.

## Структура проекта

Основная логика приложения находится в Django-приложении `office_map`.

Основные части:

- `views.py` — обработчики страниц и AJAX-запросов.
- `models.py` — модели зданий, этажей, планов, помещений, контуров и размещённых объектов.
- `services/` — вспомогательная логика, обработка DXF и генерация SVG.
- `templates/office_map/` — HTML-шаблоны страниц и компонентов.
- `templates/office_map/partials/` — отдельные шаблоны панелей, карточек и результатов поиска.
- `static/` — CSS и JavaScript приложения.

### Основные сервисы

| Файл | Назначение |
|---|---|
| `services/dxf_converter.py` | Анализ DXF, преобразование чертежей и импорт контуров помещений |
| `services/employee_renderer.py` | Генерация SVG-маркеров сотрудников |
| `services/employee_service.py` | Получение и подготовка данных сотрудников |

| Импортер библиотеки мебели | Импорт геометрии мебели из DXF |


## Работа с картой

### Помещения

Контуры помещений генерируются в SVG на основе сохранённой геометрии. Закрытые контуры, связанные с помещениями, получают номер помещения в центре многоугольника.
При выборе помещения открывается информационная панель. В ней отображаются сведения о помещении и закреплённых за ним сотрудниках.
Если у помещения отсутствует контур, оно может отображаться в результатах поиска, но перейти к его контуру на карте нельзя.

### Сотрудники

Сотрудники отображаются на плане в виде маркеров. Если фотография доступна, используется фотография; в противном случае отображаются инициалы.
Маркер можно выбрать, переместить или открыть карточку сотрудника.

### Мебель

Геометрия мебели хранится отдельно от её размещения на конкретном плане. Для отображения используется SVG.
При импорте DXF поддерживаются линейные элементы и заливки HATCH. Цвета импортированной геометрии сохраняются.

## Изменение размеров элементов на плане

### Размер кружка с номером помещения

Размер кружка задаётся при генерации SVG контуров помещений.

**Файл:** `office_map/services/dxf_converter.py`

Найди участок, в котором создаётся SVG-элемент `circle` внутри группы `room-number-badge`.

```python
'r': '10000',  # Радиус окружности с маркером помещения
```

- Увеличить значение `r` — кружок станет больше.
- Уменьшить значение `r` — кружок станет меньше.

**Размер цифры внутри кружка** задаётся отдельно, при создании SVG-элемента `text`:

```python
'style': 'font-size: 6500px !important; font-weight: 700;',
```

Изменяй `font-size`, чтобы увеличить или уменьшить номер помещения.

Обрати внимание: `r` — это радиус, а не диаметр. Диаметр круга равен удвоенному радиусу.

### Размер маркера сотрудника

**Файл:** `office_map/services/employee_renderer.py`

Для настройки размера маркера найди функцию:

```python
_get_avatar_radius()
```

Она используется для определения радиуса аватара сотрудника.

- Увеличение радиуса увеличивает изображение сотрудника.
- Уменьшение радиуса уменьшает изображение сотрудника.

При изменении размера проверь связанные SVG-элементы:
- фон маркера;
- изображение сотрудника;
- белую обводку маркера;
- текст с инициалами, если фотография отсутствует.

Если размеры этих элементов задаются отдельно, их необходимо согласовать между собой, чтобы фон, фотография и обводка не расходились.

CSS-классы маркера сотрудников:

- `.employee-marker-background`
- `.employee-avatar`
- `.employee-marker-border`
- `.employee-initials`
- `.employee-label`

Стили этих классов находятся в CSS-файле карты. Они отвечают преимущественно за оформление SVG-элементов, а геометрические размеры маркера задаются при его генерации в `employee_renderer.py`.

## Дополнительные возможности

### Открытие страницы с конкретным сотрудником

Чтобы открыть страницу определённого этажа сразу с выбранным сотрудником, можно использовать URL с GET-параметрами:

```text
http://localhost:8004/office-map/floors/01a19e42-d194-7239-a852-1947ea79f15c/?embed=1&focus_employee=01a1b51d-f5e0-77fe-801d-2757a80ca6ad
```

Параметры URL:

- `01a19e42-d194-7239-a852-1947ea79f15c` — UUID этажа.
- `embed=1` — режим отображения только текущего плана этажа.
- `focus_employee=...` — UUID размещения сотрудника из таблицы `EmployeePlacementModel`.

Чтобы открыть другого сотрудника, необходимо заменить UUID в параметре `focus_employee` на ID нужной записи `EmployeePlacementModel`.

При открытии страницы карта автоматически находит сотрудника на плане и фокусируется на соответствующем помещении.

### Поворачивание мебели

Для поворота выбранного элемента мебели используются клавиши клавиатуры:

- `Q` — повернуть мебель в одну сторону.
- `E` — повернуть мебель в противоположную сторону.

Перед нажатием клавиши необходимо выбрать элемент мебели на плане.

## Подготовка DXF-файла и загрузка плана этажа

### 1. Подготовка DXF-чертежа

Для корректной работы с планом этажа в DXF-файле должны быть предусмотрены следующие слои:

| Название слоя | Назначение |
|---|---|
| `01_WALLS` | Стены и основная геометрия плана этажа |
| `02_ROOMS` | Контуры отдельных помещений |

**Слой `01_WALLS`**
- Содержит геометрию стен и основу архитектурного плана.
- Используется при формировании общего SVG-чертежа.

**Слой `02_ROOMS`**
- Содержит контуры отдельных помещений.
- Контуры используются для дальнейшей работы с помещениями на интерактивной карте.
- Для корректного извлечения рекомендуется использовать замкнутые полилинии `LWPOLYLINE`.
- Каждый контур должен соответствовать отдельному помещению.

**Важно:** названия слоёв должны совпадать с указанными выше. Не переименовывайте их.

### 2. Загрузка DXF-файла

Порядок действий:

1. Открыть раздел управления планами этажей.
2. Создать новый план этажа или выбрать существующий.
3. Загрузить подготовленный DXF-файл.
4. Сохранить план.

Исходный DXF сохраняется в системе и используется как источник геометрии.

### 3. Преобразование DXF в SVG

После загрузки файла нажать кнопку **«Преобразовать в SVG»**.

Система автоматически:

1. Открывает исходный DXF-файл.
2. Определяет границы чертежа.
3. Преобразует геометрию чертежа в SVG.
4. Формирует SVG с сохранением слоёв.
5. Сохраняет параметры исходной системы координат DXF.
6. Сохраняет готовый SVG в плане этажа.

SVG становится графической основой интерактивной карты.

### 4. Работа с готовым планом

После успешного преобразования можно переходить к наполнению плана данными:

1. Импортировать контуры помещений из слоя `02_ROOMS`.
2. Связать контуры с помещениями в базе данных.
3. Размещать сотрудников на плане.
4. Добавлять и размещать мебель.
5. Использовать интерактивную карту для просмотра и редактирования планировки.

### 5. Важные замечания

- Исходный DXF и готовый SVG хранятся отдельно.
- DXF нужен для повторного преобразования и извлечения исходной геометрии.
- SVG используется для отображения плана в браузере.
- Система координат DXF сохраняется для правильного размещения контуров помещений, сотрудников и мебели.
- Перед загрузкой рекомендуется проверить правильность названий слоёв и геометрию контуров помещений.

## Подготовка библиотеки мебели в AutoCAD

Для импорта мебели в систему используется отдельный DXF-файл, содержащий блоки с моделями мебели.

Каждый предмет мебели должен быть оформлен как **отдельный именованный блок AutoCAD**.

### 1. Создание блоков

1. Нарисуйте геометрию предмета мебели.
2. Выделите всю геометрию одного предмета.
3. Создайте из неё блок с помощью команды `BLOCK` (`БЛОК`).
4. Задайте блоку понятное название, по которому можно определить предмет мебели.
5. Повторите эти действия для остальных предметов.

**Важно:** геометрия каждого предмета должна быть объединена именно в блок. Просто нарисованные рядом линии и фигуры не считаются отдельными блоками мебели.

### 2. Выбор базовой точки блока

При создании блока особое внимание уделите базовой точке (точке вставки).

**Базовая точка должна находиться в центре предмета мебели.**

Это необходимо для того, чтобы при добавлении мебели на план она размещалась относительно своего центра, а не смещалась в сторону.

Рекомендуется:
- располагать базовую точку в геометрическом центре предмета;
- проверять её положение перед сохранением блока;
- по возможности создавать все блоки по единому принципу.

### 3. Подготовка геометрии

При создании моделей мебели:
- используйте реальные пропорции предметов;
- следите, чтобы геометрия не содержала случайных удалённых объектов;
- проверяйте, что весь предмет находится внутри границ блока;
- по возможности используйте замкнутые области и заливки для цветных элементов;
- задавайте цвета элементов так, как они должны отображаться на плане.

### 4. Сохранение библиотеки

1. Разместите все подготовленные блоки в одном DXF-файле.
2. Сохраните файл в формате DXF.
3. Загрузите DXF-файл библиотеки мебели в систему через предусмотренный механизм импорта.

**При импорте загружаются все блоки, содержащиеся в DXF-файле.** Поэтому в библиотечном файле должны находиться только те блоки, которые действительно нужно добавить в каталог мебели.

### 5. Использование мебели на плане

После импорта модели появляются в каталоге мебели.

Из каталога можно:
- перетащить предмет на план этажа;
- перемещать его по плану;
- поворачивать клавишами `Q` и `E`;
- выбирать предмет и удалять его с плана через контекстное меню.

Важно различать библиотеку и размещение: импортированный блок становится моделью в каталоге, а добавление этой модели на этаж создаёт отдельное размещение мебели.
